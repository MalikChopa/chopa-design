Installer et lancer Tuilage

De l'installation à la première carte découpée, en cinq minutes et trois commandes.

Avant de commencer

Tuilage lit une image (PNG ou JPEG) et la découpe en carrés réguliers, les tuiles, que le jeu recharge au fil du déplacement. Il faut :

  • un terminal, quel que soit le système ;
  • environ 50 Mo d'espace libre ;
  • une image source d'au moins 1 024 pixels de large.

Installer Tuilage

Choisis ton système ; chaque onglet donne la commande à copier.

macOS

Avec Homebrew :

brew install tuilage

Linux

Sur Debian et dérivés :

sudo apt install tuilage

Windows

Avec le gestionnaire de paquets intégré :

winget install tuilage

Vérifie l'installation avec tuilage --version : elle doit afficher 2.1.0.

Découper une première carte

Place ta carte dans un dossier, ouvre un terminal dans ce dossier, puis lance :

tuilage decouper carte.png --taille 256 --sortie tuiles/

Tuilage écrit une ligne par tuile. Pour l'interrompre en route, appuie sur Ctrl+C ; les tuiles déjà écrites restent en place.

Pour ouvrir l'aperçu une fois le découpage terminé, appuie sur Espace, puis sur Échap pour le fermer.

Vérifier le résultat

Le dossier tuiles/ contient une image par case, nommée x-y.png, et un fichier index.json que le jeu lit au démarrage.

Options

Les options se placent après le nom de l'image, dans n'importe quel ordre.

Options de la commande tuilage decouper
OptionPar défautEffet
--taille256Côté d'une tuile, en pixels.
--sortietuiles/Dossier où écrire les tuiles.
--marge0Pixels recopiés de chaque côté pour éviter les coutures.
--formatpngFormat des tuiles : png ou webp.

Dépannage

Attention · si le dossier de sortie existe déjà, Tuilage refuse d'écrire pour ne rien écraser. Choisis un autre dossier ou ajoute --remplacer.

« Image trop petite »

L'image source fait moins de 1 024 pixels de large. Agrandis-la dans ton éditeur, ou passe une taille de tuile plus petite avec --taille 128.

Des coutures entre les tuiles

Le jeu applique un filtre qui mélange les bords. Ajoute deux pixels de marge pour les masquer :

tuilage decouper carte.png --marge 2

La commande est introuvable

Ferme puis rouvre le terminal : le chemin d'installation n'est lu qu'au démarrage. Si cela ne suffit pas, relance l'installation de l'onglet correspondant à ton système, plus haut sur cette page.
