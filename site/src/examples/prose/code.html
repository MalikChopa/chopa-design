Brancher la feuille de style

Ajoutez la ligne ci-dessous dans le <head> de la page, puis posez data-ch-theme="sombre" sur la balise html.

<link rel="stylesheet" href="/chopa/chopa.css">
<html lang="fr" data-ch-theme="sombre">

Un bloc long défile dans son cadre sans élargir la page :

const options = { theme: "sombre", accent: "#ff5a1f", rayon: 0, police: "Inter Tight", repli: "Helvetica Neue, Arial, sans-serif" };
